---
name: scheduling
description: Поставить, перенести, снять, показать или сразу запустить напоминание либо команду по расписанию.
---

Используй `schedule`, время передавай словами владельца. Код считает момент в его зоне.
Сообщи владельцу `next_run_at` из ответа; `scheduler.alive: false` требует назвать предупреждение.

- Поставить напоминание: `{"action":"add","text":"Найди новости и пришли итог","at":"in 30m"}`.
- Рутина: `{"action":"add","text":"Напомни про зарядку","cron":"0 9 * * 1-5"}`.
- Скрипт без модели: `{"action":"add","command":"python3 scripts/example.py","cron":"0 6 * * *"}`.
- Показать задачи и последний факт: `{"action":"list"}`. Бери id из этого списка.
- Перенести: `{"action":"move","id":"…","at":"14:30"}` либо `cron`. Id и задание сохраняются.
- Снять: `{"action":"remove","id":"…"}`.
- Запустить в ближайшую минуту: `{"action":"run_now","id":"…"}`. Рутина сохраняет своё расписание.

`text` — инструкция самой себе: в срок ты проснёшься в свежей сессии без этого чата,
выполнишь её, код отправит финальный ответ в чат и тему, где попросили.
Запиши самодостаточно, что сделать, для кого и куда. Обещание вернуться к делу поставь сама.
Ход сработавшего напоминания сообщает итог, следующие напоминания ставит обычный ход владельца.
`remind` сохраняет прежние add/list/remove для текстовых напоминаний на том же движке.

`command` — готовая shell-команда с разрешением владельца; модель для запуска свободна.
Она идёт в bash, из корня установки, с окружением сервиса и сроком 2 минуты по умолчанию.
Долгий скрипт ставь с `timeout_minutes` в add/move по обычной длительности с запасом, целое 1–60.
Успех тихий; сбой вызывает Alert с причиной, одинаковая проблема имеет недельный дроссель.
Проверяй `fired_at`, `last_status`, `error` в `list`; `log` указывает журнал в `data/`.
Журнал хранит последние 32000 символов; строки команд и журнал живут до снятия задачи.
`run_now` и `move` во время выполнения ждут его завершения и сохраняют текущий факт.
Сообщи владельцу `message` из ответа: перенос применится после идущей задачи.
Команды допускают минутный cron. После перебоя Ивы проверь факт через `list`.

Brief и Insight пока меняются через `iva proactive set briefTimes …` / `insightTimes …`.
Расписание владельца в systemd переноси строкой `command`; старый таймер выключай после одного
успешного запуска новой строки, проверенного по `list` и журналу.
