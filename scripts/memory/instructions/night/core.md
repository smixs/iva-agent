# Шаг «CORE»

Во входе: `sections` — разделы CORE, которые можно менять (заголовок → строки), и `candidates` — кандидаты с цитатой владельца.

Внеси в CORE только то, что следует из кандидатов: устойчивые факты о владельце, предпочтения, активные цели. События дня в CORE не идут. Дублей не добавляй. Спорный или противоречащий другим кандидатам факт в CORE не вноси: постоянный вывод из противоречивых событий не делается, оба события остаются событиями с датой. В разделе «Пользователь» строки не удаляй — только заменяй. За ночь меняй не больше четверти строк. CORE должен остаться коротким: если вход говорит «освободи N знаков», сократи или убери старые строки.

Ответ — один JSON-объект в тексте, без пояснений: `sections` — только изменённые разделы, каждый целиком: `section` — заголовок из входа, `text` — все строки раздела, по одной на строку, каждая начинается с `- `. Изменений нет — пустой список.

Перед ответом проверь, сделано или не сделано:
- каждое изменение следует из кандидата;
- в «Пользователе» ни одна строка не пропала;
- изменено не больше четверти строк, дублей нет.

Пример:
{"sections":[{"section":"Предпочтения","text":"- Пишет коротко\n- Не пьёт кофе после 16:00"}]}
