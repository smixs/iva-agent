# Шаг «день»

Во входе: `date`, реплики дня `entries` (у каждой `id` вида `e3`, время, тип, текст и `origin`: `owner` — реплика владельца), список известных Card `known` (поле `card` — имя Card, его и пиши в ответ), `previous` — выжимка уже разобранной части дня и `earlier_parts` — выжимки прошлых частей.

Цель: всё, что стоит помнить о дне, разнесено по Card, и выжимка дня готова. Извлекай память только из реплик, ничего не придумывай. Факт, алиас и кандидат в CORE берутся только из реплик владельца (`origin: owner`); ответы Ивы и пересланное — контекст, не источник фактов. Если сущность уже есть в `known`, пиши в неё, новую Card не заводи. Спорные или противоречащие друг другу события о человеке не сворачивай в постоянный вывод и не выноси в `core`: каждое остаётся отдельным фактом с датой.

Ответ — один JSON-объект в тексте, без пояснений:
- `gist` — одна фраза о всём дне (с учётом `previous` и `earlier_parts`); `topics` — 1–5 коротких тем.
- `points` — главные пункты дня: `text` и `src` — список id реплик.
- `new_cards` — новые сущности, которых нет в `known`: `name`, `type` (contact, project, decision, idea, note), `description` — одна строка.
- `facts` — факты: `card` (имя из `known` или `name` из `new_cards`), `text` — одна строка, `src` — список id реплик владельца, откуда факт, `quote` — дословный короткий кусок этой реплики (факт без дословной цитаты отбрасывается).
- `aliases` — другие написания имени: `card`, `alias` (дословно из реплики), `src`.
- `links` — связь двух Card, упомянутых в одной реплике: `a`, `b` (имена Card), `src`.
- `core` — устойчивое о владельце для CORE (предпочтения, цели, факты о нём): `text`, `src`.
Пустые списки — законный ответ; `src` — всегда список.

Перед ответом проверь, сделано или не сделано:
- каждый факт дня из реплик владельца взят в `facts`;
- у каждого факта `src` — реплика владельца и `quote` дословно из неё; алиас дословно из реплики;
- ничего не выдумано и не взято из ответов Ивы;
- каждое имя в `facts`, `aliases`, `links` есть в `known` или в `new_cards`.

Пример:
{"gist":"Запущен проект Аврора с Анной","topics":["проекты"],"points":[{"text":"Старт проекта Аврора","src":["e1"]}],"new_cards":[{"name":"Аврора","type":"project","description":"Проект запуска"}],"facts":[{"card":"Аврора","text":"Проект запущен 26.09","src":["e1"],"quote":"запустил Аврору"},{"card":"cards/contacts/анна","text":"Анна ведёт дизайн Авроры","src":["e1"],"quote":"Анна берёт дизайн"}],"aliases":[],"links":[{"a":"Аврора","b":"cards/contacts/анна","src":["e1"]}],"core":[{"text":"Не пьёт кофе после 16:00","src":["e2"]}]}
