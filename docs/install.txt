# Install Iva for the person

Iva is a self-hosted Telegram AI assistant with layered memory, running on the person's server or Mac.

Talk to the person in their language. Follow the install-iva skill to check the machine, install or repair Iva,
and verify that the bot answers them.

If you can install skills, download every file below into your skills directory, preserving the paths inside
skills/install-iva. Claude Code uses ~/.claude/skills/install-iva; Codex uses ~/.agents/skills/install-iva.
Keep the full SKILL.md and references together, then read SKILL.md and follow it.

Otherwise, fetch and read SKILL.md directly and follow its steps. Read each reference when its step calls for it.
Resolve references/... against the file list below.
